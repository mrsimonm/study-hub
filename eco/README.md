# Eco Hub (Fundamentals of Ecology)

A static, no-build study web app for **ČZU Prague · Fundamentals of Ecology** (Martin Bulla & Peter Mikula, winter 2026/27): 12 step-by-step lessons, a "tick all that apply" drill that scores like the real exam, 4-star Mastery, flashcards, games, mock tests, review, a searchable dictionary and the Study Cat. Fourth hub next to Geology Hub, Statistics Hub and Micro Hub, built on the same engine.

Open it at https://mrsimonm.github.io/eco-hub/

- Run locally: `python3 -m http.server 8000` → open `http://localhost:8000`
- Validate data: `node tools/validate.js courses/eco`
- Add or fix a lesson: see `AUTHORING.md` and `PROMPT.md`
- Start with `HANDOFF.md`
