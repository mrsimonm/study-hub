## Taxonomy: definition · Linnaeus & the hierarchy | 2 min
- **Taxonomy** = science of classification of living and extinct organisms; Greek ***taxis*** (arrangement) + ***nomos*** (law) (p. 3)
- Four components: **description, identification, nomenclature, classification**; grouping and naming organisms, usually **hierarchically** (p. 2–3)
- Why: to organise the **millions of species** we discover and name them by a **standard international method** (p. 4)


### Linnaeus & the hierarchy
- **Carolus Linnaeus (Carl von Linné), 1707–1778**, Swedish biologist; developed a **7-level classification** based on **similarities**; each level is more specific (p. 5)
- Ranks (broad → specific): **Kingdom → Phylum → Class → Order → Family → Genus → Species** (higher: Domain; lower: subspecies) (p. 5, p. 7)
- **Plant example** (p. 6): Kingdom *Plantae* (~280,000 spp.) → Phylum *Angiospermae* (~250,000) → Class *Dicotyledonae* (~235,000) → Order *Rosales* (~18,000) → Family *Rosaceae* (~3,500) → Genus *Rosa* (~500) → Species ***Rosa gallica*** (moss rose). Ranks have **specific endings** (e.g. -ales, -aceae)
- **Animal example** (p. 7): Domain *Eukarya* → Kingdom *Animalia* → Phylum *Chordata* → Class *Mammalia* → Order *Carnivora* → Family *Canidae* → Genus *Canis* → Species ***Canis lupus*** → Subspecies ***Canis lupus familiaris*** (domestic dog)

## Description & identification · Classification | 4 min
- **Character** = a feature (e.g. body colour); **character state** = a form of it (orange or black) (p. 8)
- **Identification keys**: **textual, usually dichotomous** (couplets: 1 Trees → 2 / Herbs → 3; 2 Leaves simple → sp. 1 / compound → sp. 2…), or **pictorial** (p. 9)


### Classification
- **Taxon (pl. taxa)** = a taxonomic group (p. 10)
- **Three types** (p. 10):
- ↳ **Intuitive**: e.g. bats grouped with birds because both fly
- ↳ **Phenetic**: based on **overall similarity**; can be **arbitrary** (p. 11)
- ↳ **Cladistic (phylogenetic)**: based on **shared advanced (derived) characters**, i.e. known or inferred **evolutionary history** (p. 12)
- Tree terms (p. 12): **branch point (node)**, **common ancestor**, **sister taxa**, **polytomy** (unresolved node with > 2 branches), ancestral lineage
- **Apomorphy** = newly evolved, **derived** character state (p. 13)
- **Synapomorphy** = **shared derived** state defining a lineage (e.g. character 1 for taxa A–C) (p. 13)
- **Autapomorphy** = derived trait unique to one taxon, e.g. **feathers for birds + related dinosaurs** (simple → vaned feathers) (p. 14–15)
- Whether a trait is syn- or autapomorphy depends on the set of taxa: **fur** is a synapomorphy for mouse, chimpanzee and human, and also for platypus, kangaroo and elephant (p. 15)
- Example matrix (lancelet as **outgroup**; lamprey, tuna, salamander, turtle, leopard): vertebral column → hinged jaws → four walking legs → **amniotic egg** (synapomorphy of turtle + leopard) → hair (p. 16)
- **Parsimony analysis** of morphological characters builds trees (beetle example) (p. 17)
- **Homology** = similarity from **common ancestry** (forelimb bones of human, cat, dolphin and bat) (p. 18)
- **Homoplasy** = similarity **not** from common ancestry, a problem for classification (p. 18–20):
- ↳ **Convergence**: e.g. **spines of cacti and euphorbs** (not closely related) (p. 19)
- ↳ **Reversal**: e.g. **reduced eyes, depigmentation** in unrelated beetles (Dytiscidae, Carabidae, Leiodidae cave forms) (p. 20)
- **Phylogenetic vs phenetic** (p. 21): phylogenetic groups by **ancestral relations** (**crocodile + bird** are sisters, lizard outside); phenetic groups by **morphological similarity** (**lizard + crocodile** together, bird outside)

## Nomenclature | 3 min
- Rules for handling biological names (mostly species, genera, families); **slightly different rules for plants (incl. fungi) and animals**; purpose: **stability** of names (p. 22)
- **Binominal nomenclature**: two names per species. **Genus capitalised**, **species epithet never capitalised**, **both italicised** (*Homo sapiens*, *Bubo bubo*, *Artemisia vulgaris*) (p. 23)
- **Botany** (p. 24):
- ↳ ***Artemisia vulgaris* L.**: author abbreviated, **no year**
- ↳ *A. vulgaris* L.: genus abbreviated
- ↳ ***Artemisia montana* (Nakai) Pamp.**: originally described by Nakai in another genus, moved by Pampanini; **original author in brackets + combining author**
- ↳ Family *Asteraceae*: **higher taxa also in italics** in botany
- **Zoology** (p. 25):
- ↳ ***Homo sapiens* Linnaeus, 1758**: author **+ year**
- ↳ *Homo sapiens sapiens* L.: subspecies (trinomen)
- ↳ *Homo (Homo) sapiens*: subgenus in brackets
- ↳ ***Pan troglodytes* (Blumenbach, 1775)**: originally *Simia troglodytes*; now in another genus, so **author + year in brackets** (the combining author is not given)
- ↳ Family Hominidae: **higher taxa not italicised** in zoology (just a convention)
- **Starting points** (p. 26): **1753 = botany and mycology**; **1758 = zoology** (Linnaeus' adoption of binominal names)
- **Codes** (p. 27):
- ↳ **ICN**: International Code of Nomenclature for algae, fungi and plants; latest **2017 (Shenzhen Code)**
- ↳ **ICZN**: International Code of Zoological Nomenclature; latest **1999**
- ↳ **ICNP**: International Code of Nomenclature of Prokaryotes (bacteria, archaea); latest **2015**
- ↳ Others: cultivated plants, viruses, plant associations
- **Universal codes** (p. 28):
- ↳ **BioCode** (draft 1997, revised 2011): harmonise terminology across botany, zoology and bacteriology
- ↳ **PhyloCode** (draft 1998): **phylogenetic nomenclature** replacing Linnaean; phylogenetic definitions as "types"; **no mandatory ranks**
- **Nomenclature only follows taxonomy**: taxonomy = science (classification); nomenclature = tool (handling and changing names) (p. 29)
- **Five basic principles: priority, availability, typification, homonymy, synonymy** (p. 29)

## The principles | 3 min
- **Priority** (p. 30–31): the **oldest name** applied to a taxon is used (published after 1753/1758); later names for the same taxon are **junior synonyms**
- ↳ Example: *Pyrochroa japonica* Heyden, **1879** (older) and *Schizotus gibbifrons* Lewis, **1887** (younger) both moved to *Pseudopyrochroa*; Young (2014) found them identical → ***P. gibbifrons* is a junior synonym of *P. japonica***
- **Availability**: conditions for a name to be valid (p. 32):
- ↳ Published after 1753 (plants) / 1758 (animals)
- ↳ Consistent **binominal** nomenclature
- ↳ **Latin alphabet only** (*mülleri* → *muelleri*)
- ↳ Printed on paper; CD-ROM only **1985–2013**; **online after 1 Jan 2013** if registered in **ZooBank** (with LSID) and archived
- **Typification** (p. 33):
- ↳ Species-group names → **holotype** (in the past syntypes), a specimen deposited in a museum (botany: may be an illustration)
- ↳ Genus-group names → **type species**
- ↳ Family-group names → **type genus**
- ↳ Example: holotype of *Pteroloma harmandi* Portevin, 1903 in the Natural History Museum, Paris
- **Homonymy** (p. 34–37):
- ↳ The **same name can't be used for different taxa**; the **senior homonym** (older) is valid; the **junior homonym** is preoccupied and must be replaced
- ↳ **One letter's difference is enough**: Laridae (birds) vs Larridae (wasps) are **not** homonyms
- ↳ Example: *Helophorus sibiricus* (Motschulsky, 1860) is the senior homonym; *Mesohelophorus sibiricus* Ponomarenko, 1977, moved to *Helophorus* (2012), became a junior homonym → replacement name ***H. paleosibiricus***
- ↳ **Homonyms are allowed across codes** (plants vs animals vs bacteria): ***Iris*** (plant genus and a mantid genus); ***Bacillus*** (bacterium, Cohn 1872, and stick insect, 1827)
- **Synonymy**: different names for the same taxon; the oldest is valid (p. 30–31)

## Scientific names · Conclusions | 2 min
- **Vernacular names** differ by language (pes, dog, Hund, собака, 狗…); **scientific names** are derived from **Latin, Greek or modern languages** (*Canis* = dog, *africanus* = African; Greek *arctos* = bear) (p. 38)
- Names from modern languages: *Jentozkus*, *Tohlezkus* Vít 1977 (Czech puns); *Bezesporum* Fikáček et al. 2022 (p. 39–40)
- Curious names: ***Aa*** (shortest, a mollusc), *Yamagutiplectognathotrema* (long), *Aaadonta* and *Zyzzyxdonta* (snails), ***Oops*** (spider), ***This*** (fly, "Look at This!") (p. 41)
- Longest: ***Parastratiosphecomyia stratiosphecomyioides*** (fly, 42 characters) (p. 42); ***Myxococcus llanfairpwllgwyngyllgogerychwyrndrobwllllantysiliogogogochensis*** (bacterium, 2020, 64 characters, after a Welsh village) (p. 43)
- ***Agra*** beetles (> 600 spp.; Terry Erwin named about half): *Agra cadabra*, *A. vation*, *A. phobia*, *A. schwarzeneggeri* (p. 44)
- ***Spongiforma squarepantsii*** (fungus), ***Agathidium vaderi*** (beetle), ***Neopalpa donaldtrumpi*** (moth), ***Daimophyllon dio*** and ***D. ozzyosbournei*** (rove beetles, 2025) (p. 45–49)


### Conclusions
- **Cladistic classification is preferred**; modern classifications are lacking for many groups
- Nomenclature has complex rules; **ask a taxonomist** before publishing names (even in ecology papers)


## Processes step by step | 2 min
### Using a dichotomous key (p. 9)
Read couplet 1 → choose the matching alternative → go to the indicated couplet → repeat until a species name is reached

### Resolving names (p. 30–35)
1. Is the name **available**? (date, binominal, Latin alphabet, proper publication)
2. Same taxon, several names → **priority**: the oldest is valid; others are junior synonyms
3. Same name, different taxa in one code → **homonymy**: the junior homonym gets a replacement name
4. Names are anchored by **types** (holotype, type species, type genus)
